Validation and methodology

  • Record the profile, scene, resolution, graphics settings, driver, and repeat count.
  • Identify every measurement source and mark missing or degraded data visibly.
  • Reject invalid runs; do not silently include them in averages.
  • Users must install each game or benchmark themselves and have a valid license or other legitimate access.
  • A profile does not bypass publisher licenses, accounts, anti-cheat systems, or terms of service.
