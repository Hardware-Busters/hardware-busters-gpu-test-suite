# PresentMon bootstrap

This repository does not ship PresentMon binaries. Download a release directly from the official PresentMon project, verify the published checksum and release provenance, review the upstream license, and place the executable at `tools/PresentMon/PresentMon.exe` for local use.

Do not commit the executable. See `Install-PresentMon.ps1` for a guarded local placement helper. Upstream terms and attribution belong in [NOTICE](../../NOTICE).
