# PresentMon bootstrap

This repository does not ship PresentMon binaries. Download the official standalone x64 PresentMon 2.6.0 console executable from the [upstream v2.6.0 release](https://github.com/GameTechDev/PresentMon/releases/tag/v2.6.0), verify its published SHA-256 (`b2a706bc6ad475749e3b7e3409263aa1e6906d45bdcf993f6dbc0f660188f1af`) and release provenance, review the upstream license, and place it at `tools/PresentMon/PresentMon.exe` for local use.

Do not commit the executable. See `Install-PresentMon.ps1` for a guarded local placement helper. Upstream terms and attribution belong in [NOTICE](../../NOTICE).
