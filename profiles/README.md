# Public profile policy

`PROVENANCE.md` is the complete, explicit public inventory. The curated official pack is Hardware Busters Verified and Apache-2.0; the three disabled samples are Community content under CC-BY-4.0.

Community profiles must be reproducible, free of private machine paths, game-generated configuration, media, accounts, results, and copyrighted assets. Submit them through a pull request using the profile checklist. Maintainers may label an accepted profile **Community**; only Hardware Busters maintainers may apply **Verified** after documented independent review.

Profiles contain automation instructions, not the games or benchmark applications they target. Users must install the target software themselves and must have a valid license or other legitimate access to it. A profile must never include or bypass commercial game files, accounts, license checks, anti-cheat systems, or publisher terms.
