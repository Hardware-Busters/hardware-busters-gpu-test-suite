Hardware Busters GPU Test Suite — full automated game-benchmark workflow requirements

Elgato Game Capture 4K Pro is the only capture-card model currently qualified by this project. Elgato 4K X is permitted for experimental automated vision capture and is not independently qualified by Hardware Busters.

Official product identification: Elgato Game Capture 4K Pro, SKU 10GBK9901 — https://www.elgato.com/us/en/p/game-capture-4k-pro
This identifies the qualified product; experimental admission does not establish independent hardware qualification.

Configure settings.captureCardDevice to the exact DirectShow name: Elgato 4K Pro (qualified default), or Elgato 4K X (experimental).
Confirm the exact name with: gpusuite grab --list

The configured device itself must be enumerated and pass the bounded stream probe. An experimental 4K X shows a warning; a missing/mismatched device or failed stream still blocks automation.

Elgato 4K60 Pro, Elgato 4K60 Pro MK.2, generic devices, and other cards remain diagnostic-only. They are not necessarily incompatible: offline authoring, builds, and diagnostic capture commands may still work.

Full pre-flight checks the enabled roster's PresentMon/RTSS FPS and frametime requirement separately from FFmpeg and the Elgato vision stream. It runs a bounded stream probe; no image is retained, and this vision input is never used as an FPS source. An advanced launch override cannot bypass runtime frame validation.

The 60 Hz display safety setting applies to this validated bench path; it is not a general product limit.
